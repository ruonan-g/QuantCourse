# 回测测试想法清单（动量 / 趋势型系统）

> **当前系统能力**：数据 = 个股复权日频行情（`hfq_clean.csv`，无成交量、无指数、无财务）。
> 适用于**动量 / 趋势 / 突破类**信号（均线交叉、动量、突破、累计收益）。
> 价值 / 基本面 / 反转型想法只能以「代表性个股 + 动量代理」验证，结论不等同于想法本身成立，报告会标注「仅供参考」。
>
> **如何运行**：在 PyCharm 直接跑 `main.py` 并在控制台输入想法；或 CLI：
> ```bash
> echo "你的想法" | PYTHONPATH="项目根/src" 你的python main.py
> ```
> （隔离环境示例：`PYTHONPATH="E:/Socia-Practice/summer_intern2/ai_subinvest_intern/src" "C:/Users/Lenovo/.workbuddy/binaries/python/envs/default/Scripts/python.exe" main.py`）

## 一、可直接验证（板块 / 行业级动量）✅

### 1. 半导体设备突破年线（投资经理 · 详细）
> 半导体设备板块（北方华创、中微公司、拓荆科技、华海清科），股价突破 60 日年线后等权买入持有，跌破 60 日线卖出；季度调仓，单票仓位不超过 15%。

- 信号：组合净值 > MA250 买入，< MA60 卖出
- 系统：板块级等权篮子 + 均线交叉，参数由 D 给，E 忠实实现 ✓

### 2. 白酒龙头 20 日线动量（散户 · 详细）
> 白酒龙头贵州茅台、五粮液、泸州老窖，站上 20 日均线就买、跌破就卖，满仓干。

- 信号：行业净值 > MA20 买入，< MA20 卖出
- 注意：满仓单行业风险高，D 会触发保守模式（半仓 + 分批 + 止损）

## 二、模糊型（散户口吻，系统自动识别为板块级动量）⚠️

### 3. 机器人概念趋势跟随（散户 · 模糊）
> 最近具身智能概念很火，跟着趋势买，涨了就拿跌了就跑。

- 系统：识别为板块级 → 挑代表性机器人个股 → 动量信号回测（代理）
- 注意：想法模糊，D 补默认动量参数；验证的是「机器人篮子趋势跟踪」而非你的择时直觉

### 4. AI 算力回调上车（散户 · 模糊）
> AI 算力这条线一直强势，回调到 20 日线就上车。

- 系统：板块级 + MA20 回踩买入信号（净值从高位回踩均线买入）
- 注意：需 D 把「回调到 20 日线」转成可执行条件（净值 < MA20 且前期在 MA20 上方）

## 三、系统只能代理验证（价值 / 反转型，标注清楚）🔶

### 5. 新能源跌多了该反弹（散户 · 模糊 · 反转型）
> 新能源跌这么多了该反弹了吧，抄底。

- 系统：无基本面数据，只能以「新能源篮子跌破后反弹」的动量 / 反转信号代理
- **不等于「抄底价值成立」**；报告会标注仅供参考
- 提示：反转信号需自定义（如「从区间低点反弹 X% 买入」），默认动量模板不直接覆盖，D 可能退化成动量

### 6. 红利低波月度动量（投资经理 · 详细 · 但数据缺失）
> 中证红利低波 ETF，月度动量排名前 50% 持有、后 50% 换仓。

- 系统：⚠️ ETF / 指数不在个股行情（`hfq_clean.csv` 无指数），需改用具体红利成分股；月度频率需改回测粒度
- 注意：当前数据无 ETF，需替换为代表性红利个股篮子（如银行 / 煤炭 / 公用事业龙头）

### 7. 企业估值
